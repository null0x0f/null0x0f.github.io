# Kk-CEtest_V0002项目修改

## 修改需求：自动补液：出水压力低于180打开补液泵，直至压力高于250关闭

## 修改代码

在APP_IO.c中修改
```c
#define FILL_PRESSURE_ON   180
#define FILL_PRESSURE_OFF  250

static boolean_T filling_pump_on = false;


void Outputs(void)
{
	if (ADC_pOutWaterPrsFlt < FILL_PRESSURE_ON)
	{
   	 	filling_pump_on = true;
	}
	else if (ADC_pOutWaterPrsFlt > FILL_PRESSURE_OFF)
	{
    	filling_pump_on = false;
	}
	
	PINS_DRV_WritePin(PTC,9,filling_pump_on);
}
```
PTC和9根据文档来看

## 如何根据文档看引脚位置
先在cad中查看补液泵的继电控制在哪个位置
![kancad.png](public/images/kancad.png)
再到文档的控制器接口说明去找引脚
![chakanyinjiao.png](public/images/chakanyinjiao.png)
1E对应的就是PTC9,所以代码中相对的`PINS_DRV_WritePin(PTC,9,filling_pump_on);`

## 编译烧录
修改完之后，点击导航栏中的Project的buildall进行编译，编译通过后会在项目的debug目录下生成一个bin文件
烧录用qflash，利用刚刚生成好的bin文件来进行烧录就好了
